## Description complète (max. 4000 caractères)

```
MazePrint transforme votre téléphone Android en une véritable fabrique à labyrinthes.

Générez un labyrinthe différent à chaque fois, résolvez-le avec le doigt, puis imprimez-le en PDF pour profiter du puzzle sur papier — seul, entre amis ou en famille.

────────────────────────────
🔲 LABYRINTHES CARRÉS & ⬡ HEXAGONAUX
────────────────────────────
Deux types de labyrinthe pour ne jamais s'ennuyer :
• Labyrinthes carrés — grilles rectangulaires classiques, pour tous les niveaux
• Labyrinthes hexagonaux — cellules hexagonales pour un défi spatial unique

────────────────────────────
🎮 CONTRÔLES FLUIDES
────────────────────────────
• Faites glisser le doigt pour déplacer le joueur dans n'importe quelle direction
• Touchez une cellule accessible pour y aller directement
• La trace montre par où vous êtes passé — elle s'estompe avec le temps pour maintenir le défi
• La caméra vous suit avec un défilement fluide
• Bouton vue d'ensemble pour voir le labyrinthe entier
• Chronomètre et compteur de déplacements

────────────────────────────
🏆 4 NIVEAUX DE DIFFICULTÉ
────────────────────────────
• Facile — petit labyrinthe, longs couloirs (algorithme DFS)
• Moyen — équilibré, plus de bifurcations (algorithme de Prim)
• Difficile — grand labyrinthe, nombreux points de décision
• Extrême — grille immense pour les joueurs les plus passionnés

────────────────────────────
📄 PDF PRÊT À IMPRIMER
────────────────────────────
Créez un PDF imprimable en quelques secondes :
• De 1 à 5 labyrinthes par PDF — même niveau ou progression de difficulté
• Mise en page automatique : 4 labyrinthes/page pour Facile/Moyen, 1/page pour Difficile/Extrême
• Titre personnalisé pour votre impression
• Numéro de graine sur chaque labyrinthe (pour le reproduire plus tard)
• Optimisé pour le papier A4
• Partagez ou imprimez directement depuis votre téléphone

────────────────────────────
🌙 THÈME SOMBRE · 🌍 6 LANGUES
────────────────────────────
Interface sombre élégante, agréable pour les yeux.
Disponible en : Italien, Anglais, Espagnol, Portugais, Français, Allemand.

────────────────────────────
🔒 CONFIDENTIALITÉ
────────────────────────────
Aucun compte requis. Fonctionne 100 % hors ligne. Les paramètres et scores sont enregistrés uniquement sur votre appareil.

MazePrint est gratuit et soutenu par une publicité non intrusive.
```
